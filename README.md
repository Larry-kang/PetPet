# PetPet：毛孩社群作品

原始 PetPet 為 Larry Kang 於轉職職訓期間撰寫的 ASP.NET MVC 作品；PetPet.Modern 為後續 .NET 8 改造。

## 版本與目前狀態

| 版本 | 內容與狀態 |
| --- | --- |
| [PetPet 原始版](PetPet/) | 職訓期間自行撰寫的 .NET Framework／ASP.NET MVC 作品 |
| [PetPet.Modern 公開版本](PetPet.Modern/) | .NET 8 改造程式，現有公開設定使用 SQL Server |
| SQLite 本機展示版 | 以 Agent 協作改造，具合成資料、啟動腳本及測試；已完成人工展示驗收，尚未同步至公開程式庫 |

目前下載本程式庫，不會取得上述 SQLite 展示版。展示版公開交付後會更新入口與執行步驟。本作品未對外部署營運。

## 開發分工

原始 MVC 版本由本人撰寫。Modern 改造中，定義功能規格、展示情境與驗收條件，透過 Agent 協作建立程式並核對操作結果；各版本的功能與完成程度分開記錄。
