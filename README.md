# PetPet：職訓作品與 Agent 協作改造

## 專案背景與本人貢獻

原始 PetPet 由 Larry Kang 於轉職職業訓練期間撰寫；PetPet.Modern 為後續透過 Agent 協作推進的 .NET 8 改造。兩個版本的作者貢獻與開發方式分開呈現。

- **原始版本**：本人手寫的職訓作品，以 .NET Framework／ASP.NET MVC 為基礎。
- **Modern 版本**：程式改造主要由 Agent 完成；本人透過對話討論需求、規格及功能，並查看成果進行驗收。

Modern 中的新工具與架構屬 AI 協作作品經驗，不等同本人已能獨立維護全部程式，亦不表示 RabbitMQ、Docker 等工具為本人正式工作核心專長。
